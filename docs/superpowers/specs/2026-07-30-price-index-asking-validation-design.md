# 실거래 가격지수와 호가 타당성 분석 설계

작성일: 2026-07-30
상태: 사용자 설계 승인

## 1. 목표

사용자가 검토 중인 매물의 타입, 동, 실제 층과 호가를 입력하면 다음을 한 화면에서 제공한다.

- 타입·동·층 구성 차이를 보정한 단지 실거래 가격지수
- 과거 유사 거래를 최신 가격 수준으로 환산한 적정가격
- 적정가격의 예상 범위와 입력 호가의 차이
- 호가 판정, 신뢰도, 사용한 거래 수와 판단 근거

호가는 사용자가 네이버부동산 또는 중개사 등에서 확인한 값을 직접 입력한다. 실거래가는 기존 국토교통부 실거래가 API와 초기 데이터에서 가져온다.

## 2. 접근 방법

가격지수와 보정 비교사례를 결합한 혼합형을 사용한다.

단일 회귀모형은 간결하지만 거래가 적은 동이나 분기에 결과가 모델 가정에 민감하다. 단순 최근 거래 비교는 시점 차이를 제대로 반영하지 못한다. 혼합형은 시점 보정은 회귀 기반 지수로 수행하고, 최종 적정가격은 실제 유사 거래를 가중 집계하여 안정성과 설명 가능성을 함께 확보한다.

## 3. 실거래 가격지수

### 3.1 분석 표본

- 가격이 0보다 크고 타입, 실제 층, 계약일을 사용할 수 있는 거래만 포함한다.
- 동이 공개된 거래는 동 효과 추정에 사용한다.
- 동 미공개 거래도 단지 전체 시점 효과 추정에는 사용한다.
- 취소 거래는 기존 데이터 수집 단계에서 제외한다.

### 3.2 모형

로그 거래가격을 종속변수로 두고 다음 효과를 분리한다.

- 분기 효과
- 평면 타입 효과
- 동 효과
- 실제 층 효과

실제 층 효과는 층 구간 하나로 뭉개지 않고 `floor`, `max(floor - 5, 0)`, `max(floor - 15, 0)`의 세 구간 선형 항으로 표현한다. 동 효과에는 거래 5건에 해당하는 릿지 페널티를 적용해 거래가 적은 동의 추정치를 단지 평균 쪽으로 축소한다. 타입과 분기 효과에는 페널티를 적용하지 않는다.

월평균 거래량이 적으므로 기본 지수 단위는 분기로 한다. 각 분기의 보정 가격 수준을 지수화하고 최신 분기를 100으로 둔다.

유효 거래가 30건 미만이면 지수를 계산하지 않는다. 거래가 3건 미만인 분기는 계산에는 포함하되 화면에서 `표본 적음`으로 표시한다.

### 3.3 출력

- 분기별 지수
- 전 분기 대비 변화율
- 1년 전 대비 변화율
- 분기별 거래 수
- 표본이 적은 분기 표시

가격지수는 단지 내 가격 수준의 상대 변화이며 미래 가격 예측값이 아님을 명시한다.

## 4. 호가 타당성 분석

### 4.1 사용자 입력

- 평면 타입
- 동
- 실제 층
- 호가
- 선택 입력: 매물 메모 또는 링크

호가는 자동 수집하지 않는다. 공식 실거래가 API에는 호가가 없고, 특정 민간 사이트 화면 크롤링에 의존하지 않기 위함이다.

### 4.2 비교사례 선택과 현재가 환산

1. 같은 평면 타입의 거래를 기본 후보로 선택한다.
2. 같은 동 거래가 8건 이상이면 같은 동만 사용한다.
3. 같은 동 거래가 8건 미만이면 단지 전체 같은 타입 거래로 확장한다.
4. 각 거래가격을 해당 거래 분기와 최신 분기의 가격지수 비율로 환산한다.
5. 회귀모형의 동·층 효과를 이용해 비교 거래를 입력 동·입력 층 조건으로 추가 환산한다.
6. 최신 거래일수록 더 높은 가중치를 부여한다. 시간 가중치는 2년 반감기의 지수 감쇠를 사용한다.
7. 환산 거래 중 가중치가 큰 최대 30건을 최종 비교사례로 사용한다.

적정가격은 현재가·동·층 조건으로 환산한 거래들의 가중 중앙값으로 계산한다. 예상 범위는 같은 값의 가중 20백분위와 80백분위로 계산한다.

### 4.3 판정

입력 호가가 예상 범위 안이면 `적정 범위`로 표시한다. 범위 밖에서는 적정가격 대비 차이와 불확실성을 함께 고려해 다음 중 하나를 표시한다.

- 저평가 가능
- 적정 범위
- 다소 높음
- 높음
- 판단 자료 부족

판정 경계는 다음과 같이 고정한다.

- 호가가 예상 범위 하한보다 낮음: `저평가 가능`
- 호가가 예상 범위 안: `적정 범위`
- 호가가 상한보다 높지만 상한의 105% 이하: `다소 높음`
- 호가가 상한의 105%보다 높음: `높음`

최종 비교사례가 8건 미만이거나 예상 범위 폭이 적정가격의 20%를 넘으면 가격 방향을 단정하지 않고 `판단 자료 부족`을 표시한다.

### 4.4 신뢰도

신뢰도는 다음 기준으로 `높음`, `보통`, `낮음`을 표시한다.

- 유효 비교사례 수
- 같은 동 비교사례 비율
- 입력 층과 비교사례 층의 거리
- 최근 거래 비중
- 백테스트 오차

각 등급 옆에 사용 거래 수와 대표적인 근거를 함께 표시한다.

- `높음`: 비교사례 20건 이상, 같은 동 거래 비율 50% 이상, 백테스트 중앙 절대 백분율 오차 7.5% 이하
- `보통`: 비교사례 10건 이상, 백테스트 중앙 절대 백분율 오차 12.5% 이하
- `낮음`: 판정 가능한 나머지 경우

## 5. 화면 설계

### 5.1 실거래 가격지수 영역

- 최신 지수, 전 분기 대비, 1년 대비를 요약 카드로 표시한다.
- 분기별 지수는 선 그래프로, 거래 수는 보조 정보로 표시한다.
- 표본이 적은 분기는 흐리게 표시하거나 경고 표식을 붙인다.
- 모바일에서는 요약 카드와 지수 그래프가 먼저 보이게 한다.

### 5.2 호가 타당성 영역

기존 `검토 중인 매물 가격 비교`를 확장한다.

- 타입, 동, 실제 층, 호가 입력
- 적정가격과 예상 범위
- 호가 차이와 판정
- 신뢰도와 사용 거래 수
- 현재가로 환산한 주요 유사 거래
- 표본 확장 또는 자료 부족 안내

기존 Apple 스타일, 카드 간격과 모바일 반응형 규칙을 유지한다.

## 6. 오류와 경계 상황

- 전체 유효 거래가 30건 미만이면 가격지수와 판정을 표시하지 않는다.
- 최신 분기에 거래가 없으면 거래가 존재하는 가장 최근 분기를 기준 100으로 사용한다.
- 선택한 동의 거래가 부족하면 같은 타입의 단지 전체 거래로 확장한다.
- 같은 타입 거래가 8건 미만이면 `판단 자료 부족`을 표시한다.
- 입력 호가가 없거나 0이면 가격지수만 표시하고 호가 판정은 생략한다.
- 입력 층이 1층 미만 또는 기존 데이터의 최고층보다 높으면 검증 메시지를 표시한다.
- 동 미공개 거래는 특정 동의 근거로 사용하지 않는다.

## 7. 검증

### 7.1 단위 테스트

- 최신 분기 지수가 정확히 100인지 확인
- 구성 차이만 있는 표본에서 지수가 불필요하게 움직이지 않는지 확인
- 시장가격만 상승한 표본에서 지수가 상승률을 복원하는지 확인
- 과거 거래의 현재가 환산 계산 확인
- 같은 동, 가까운 층, 최근 거래의 가중치 우선순위 확인
- 같은 동 표본 부족 시 단지 전체로 확장하는지 확인
- 호가 판정 경계와 자료 부족 처리 확인
- 신뢰도 등급 계산 확인

### 7.2 백테스트

각 거래를 해당 시점 이전 거래만으로 예측하는 시간 순서 백테스트를 수행한다. 미래 거래가 과거 예측에 섞이지 않게 하며, 다음 지표를 계산한다.

- 중앙 절대 오차
- 중앙 절대 백분율 오차
- 예상 범위 포함률

백테스트 결과는 신뢰도 산정과 화면 설명에 사용한다.

### 7.3 화면 검증

- Streamlit 렌더링 테스트
- 360×800 모바일 화면
- 1280×900 데스크톱 화면
- 빈 입력, 부족한 표본과 정상 입력 경로
- 차트와 입력 영역의 글자 겹침 및 가로 넘침 여부

## 8. 범위 제외

- 민간 부동산 사이트의 호가 자동 크롤링
- 미래 가격 예측
- 여러 단지 동시 비교
- 매물 등록·삭제 이력을 이용한 소진 기간 분석
- 금리, 학군, 교통 등 외부 변수 결합
